El login permite identificar a un usuario antes de darle acceso a la plataforma, gracias a la autenticación es posible controlar quién puede utilizar determinadas funciones, algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes, solo los usuarios autorizados deben acceder a ellas. No se deben exponer públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles. Esto ayuda a proteger la privacidad y la seguridad de la comunidad
