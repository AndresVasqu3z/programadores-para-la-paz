Comando uname -a:
Muestra información detallada del sistema operativo, incluyendo el nombre del sistema, versión del kernel, arquitectura y fecha de compilación.

Comando whoami:
Muestra el nombre del usuario que está utilizando actualmente el sistema.

Importancia:
Conocer la información del sistema es útil para administrar servidores porque permite identificar el entorno de trabajo, verificar compatibilidad de software, solucionar problemas técnicos y gestionar permisos de usuarios de manera adecuada.
