Sistema operativo:
Es el software principal que administra los recursos del computador. Permite ejecutar aplicaciones y gestionar procesos, memoria y archivos.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para desarrollar aplicaciones de servidor.

Aplicación server.js:
Es el archivo que contiene la lógica del servidor. Define las rutas y respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación utilizado por las aplicaciones para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del sistema. Ayudan a monitorear el funcionamiento y detectar errores.
